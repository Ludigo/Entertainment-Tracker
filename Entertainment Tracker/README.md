# Entertainment Tracker

A Windows desktop application for tracking games, movies, shows and books.

## Run locally

1. Install Python 3.10+ with Tkinter support.
2. Run `python -m pip install -r requirements.txt`.
3. On Windows, launch `Entertainment Tracker.bat`, or run `python src/main.py`.
4. The application creates a new, empty SQLite database in `data/` on first run.

## Privacy

This is a clean source-code copy. It contains **no personal collection database, downloaded covers, screenshots, artwork or saved API credentials**. Never commit your `data/` folder or local downloaded media. Keep backups of your personal installation separately.

## Notes

This is a source snapshot prepared from a private working archive. The Windows GUI has not been tested in this environment.
